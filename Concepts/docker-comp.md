# Docker Compose

- Docker Compose is a tool that allows you to define and manage multi-container Docker applications. 
- With a single command, you can start, stop, and rebuild services defined in a YAML configuration file. 
- It's especially useful for defining applications that require multiple interconnected services, like a web server, database, and cache.
---
### Key Concepts

- **Service**: A service defines a container that runs a specific image. Services can be scaled and connected to other services.
- **Network**: Networks define how services communicate with each other.
- **Volume**: Volumes are used to persist data generated by and used by Docker containers.
---
### Docker Compose File (docker-compose.yml)

A `docker-compose.yml` file is used to configure your application’s services, networks, and volumes. Here’s an example of a basic `docker-compose.yml` file:

```yaml
version: '3'

services:
  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: root
      MYSQL_DATABASE: test_db
      MYSQL_USER: root
      MYSQL_PASSWORD: root
    ports:
      - "3306:3306"
    volumes:
      - mysql_data:/var/lib/mysql

  zookeeper:
    image: confluentinc/cp-zookeeper:latest
    environment:
      ZOOKEEPER_CLIENT_PORT: 2181
      ZOOKEEPER_TICK_TIME: 2000
    ports:
      - "2181:2181"
    volumes:
      - zookeeper_data:/var/lib/zookeeper

  kafka:
    image: confluentinc/cp-kafka:latest
    depends_on:
      - zookeeper
    environment:
      KAFKA_BROKER_ID: 1
      KAFKA_ZOOKEEPER_CONNECT: zookeeper:2181
      KAFKA_ADVERTISED_LISTENERS: PLAINTEXT://kafka:9092
      KAFKA_OFFSETS_TOPIC_REPLICATION_FACTOR: 1
    ports:
      - "9092:9092"
    volumes:
      - kafka_data:/var/lib/kafka

volumes:
  mysql_data:
  zookeeper_data:
  kafka_data:
```

### Breakdown of the Example:

1. **MySQL Service**:
   - **Image**: `mysql:8.0`
   - **Environment Variables**: Sets the root password, database name, user, and user password.
   - **Ports**: Exposes port `3306` to the host.
   - **Volumes**: Persists MySQL data in the `mysql_data` volume.

2. **Zookeeper Service**:
   - **Image**: `confluentinc/cp-zookeeper:latest`
   - **Environment Variables**: Configures Zookeeper with client port `2181` and tick time `2000`.
   - **Ports**: Exposes port `2181` to the host.
   - **Volumes**: Persists Zookeeper data in the `zookeeper_data` volume.

3. **Kafka Service**:
   - **Image**: `confluentinc/cp-kafka:latest`
   - **Depends On**: Ensures the `zookeeper` service starts before Kafka.
   - **Environment Variables**: Configures Kafka with broker ID, Zookeeper connect string, advertised listeners, and offsets topic replication factor.
   - **Ports**: Exposes port `9092` to the host.
   - **Volumes**: Persists Kafka data in the `kafka_data` volume.

### Basic Commands

Here are some basic commands to get you started with Docker Compose:

- **docker-compose up**
  - **Description**: Starts and runs all the services defined in the `docker-compose.yml` file.
  - **Usage**:
    ```bash
    docker-compose up
    ```

- **docker-compose down**
  - **Description**: Stops and removes all the services and networks defined in the `docker-compose.yml` file.
  - **Usage**:
    ```bash
    docker-compose down
    ```

- **docker-compose ps**
  - **Description**: Lists all the services defined in the `docker-compose.yml` file.
  - **Usage**:
    ```bash
    docker-compose ps
    ```

- **docker-compose build**
  - **Description**: Builds or rebuilds the services defined in the `docker-compose.yml` file.
  - **Usage**:
    ```bash
    docker-compose build
    ```
